# AI-01 · Проверка понимания

Заполни после [задачи](task.md), до чтения ориентиров. Ответы своими словами, с ссылкой на собственный код/тест, по 3–6 предложений. По возможности сначала без AI. На защите наставник уточняет детали и даёт небольшое изменение.

1. Зачем стабильный chunkId при перестроении?

2. Почему нельзя сравнивать индексы, если corpus незаметно изменился?

3. Что может не найти lexical baseline?

4. Назови один сценарий, который твои тесты пока не проверяют. Как добавишь его и что ожидаешь увидеть?

Вопросы 1–3 оцениваются по 0–2 балла: 0 — неверно/нет объяснения, 1 — верно, но без привязки к реализации, 2 — верно с кодом/тестом и разбором ошибки. Ориентир усвоения: минимум 4/6, без нуля по ключевому вопросу 1. Вопрос 4 — материал для обсуждения, без дополнительного балла. Это часть оценки задачи, не отдельный бонус.
