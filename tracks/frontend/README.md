# Frontend · Vue 3 и TypeScript

Vue 3 создаёт интерфейс из компонентов и реактивного состояния. TypeScript помогает удерживать контракт данных между компонентами и API. В кабинете специалиста важны читаемые единицы и время, предсказуемые фильтры и различимые состояния загрузки/ошибки.

Vue Router, Pinia, Vitest и Playwright здесь — учебные рекомендации. Можно обойтись простым composable store, если это уменьшает сложность и решение объяснимо.

## Где эти технологии применяются в ТМХ

1. Vue используется для web-интерфейса специалиста. В задании это синтетическая карточка субъекта и таблица Reading.

2. Просмотр динамики требует фильтров и временных диапазонов. В задании фильтр синхронизируется с URL и проверяется без backend.

3. Ошибки сети и права доступа влияют на состояние интерфейса. В задании fake API позволяет проверить 401, 403 и 503.

Это общие функциональные примеры. Поля и endpoints упражнений относятся к PulseLab, не раскрывают реализацию продукта.

## Что изучить перед задачами

1. HTML/CSS, semantic markup, focus и формы.
2. Vue: props/emits, ref/computed, composables, lifecycle.
3. Типизированный API boundary, URL state и гонки запросов.
4. Component-тесты и ограниченные E2E-сценарии.
