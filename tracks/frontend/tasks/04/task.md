# FE-04 · Форма и ошибки сохранения

Направление: [Frontend · Vue 3 и TypeScript](../../README.md). Ориентир: 8–12 часов после изучения темы. Предыдущий шаг: FE-03.

## Цель

Отличать локальную валидацию от серверного результата.

## Входные материалы

[PulseLab](../../../../docs/01-project/pulselab.md), [fixtures](../../../../shared/fixtures/README.md), [контракты](../../../../shared/contracts/README.md). Используй свой код предыдущего задания; внешний backend/аккаунт/оборудование не являются зависимостью.

## Сделать

Сделай форму ручного ReadingInput на mock POST. Поддержи 201, 200-повтор, 409-конфликт, 422 и timeout. externalId генерируется один раз на попытку создания и сохраняется при повторе.

Сначала опиши план из 3–5 шагов, затем реализуй минимальный путь и проверь ошибки. Если выбираешь другую библиотеку, объясни совместимость с технологией направления; замена основного стека требует согласования наставника.

## Критерии приёмки

- [ ] Двойное нажатие не создаёт два запроса/две логические операции.
- [ ] Серверная 422 привязана к понятному сообщению; введённые значения сохраняются.
- [ ] Timeout не отображается как подтверждённый успех; retry использует тот же ключ.
- [ ] Тесты покрывают double-click, lost response и 409; сохранение обновляет список только после подтверждения.
