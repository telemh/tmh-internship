# FE-01 · Типы и API-адаптер

Направление: [Frontend · Vue 3 и TypeScript](../../README.md). Ориентир: 6–8 часов после изучения темы. Предыдущий шаг: Вводная диагностика и подготовка среды.

## Цель

Построить границу данных до интерфейса.

## Входные материалы

[PulseLab](../../../../docs/01-project/pulselab.md), [fixtures](../../../../shared/fixtures/README.md), [контракты](../../../../shared/contracts/README.md). Используй свой код предыдущего задания; внешний backend/аккаунт/оборудование не являются зависимостью.

## Сделать

Создай Vue 3/TS-проект. Опиши Reading, ReadingFilter и ReadingPage по учебному контракту; реализуй mock repository с fixtures и runtime-проверкой входа. Добавь selectors для s001 и kind.

Сначала опиши план из 3–5 шагов, затем реализуй минимальный путь и проверь ошибки. Если выбираешь другую библиотеку, объясни совместимость с технологией направления; замена основного стека требует согласования наставника.

## Критерии приёмки

- [ ] Нет any в доменной модели и transport boundary без объяснённой причины.
- [ ] Unknown JSON проверяется до использования; неверные unit/kind дают контролируемую ошибку.
- [ ] Фильтрация не изменяет исходный массив; сортировка соответствует контракту.
- [ ] Проверены пустой набор, испорченный объект и повтор одинакового запроса; build/typecheck проходят.

## Как изучать

Не нужно читать все руководства целиком: открой разделы по теме текущей задачи. Полный маршрут изучения указан во [вводной направления](../../README.md).

- [Vue 3 Guide](https://vuejs.org/guide/introduction.html)
- [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html)
- [Vue Router](https://router.vuejs.org/)
- [Pinia](https://pinia.vuejs.org/)
- [Vitest](https://vitest.dev/guide/)
- [Playwright](https://playwright.dev/docs/intro)
- [MDN HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Overview)

Пример промпта: «Изучаю Frontend · Vue 3 и TypeScript для учебного FE-01. Объясни понятия, необходимые для цели “Построить границу данных до интерфейса.”, и дай маленькие отдельные упражнения. Не решай задание целиком. Сверяй API с моей версией и официальной документацией».
