# MO-01 · Модель измерения и работа с JSON

Направление: [Mobile · Dart и Flutter](../../README.md). Ориентир: 6–10 часов после изучения темы. Предыдущий шаг: Вводная диагностика и подготовка среды.

## Цель

Освоить типизированную модель и отделить парсинг от интерфейса.

## Входные материалы

[PulseLab](../../../../docs/01-project/pulselab.md), [fixtures](../../../../shared/fixtures/README.md), [контракты](../../../../shared/contracts/README.md). Используй свой код предыдущего задания; внешний backend/аккаунт/оборудование не являются зависимостью.

## Сделать

Создай Dart-пакет или Flutter-проект. Прочитай readings.json, реализуй Reading и безопасный parser. Выведи записи s001 отдельно по kind; вычисли count и среднее для каждого kind, не смешивая единицы.

Сначала опиши план из 3–5 шагов, затем реализуй минимальный путь и проверь ошибки. Если выбираешь другую библиотеку, объясни совместимость с технологией направления; замена основного стека требует согласования наставника.

## Критерии приёмки

- [ ] Все 12 записей читаются; для s001 показано 8 записей: 4 heart_rate и 4 glucose.
- [ ] Неверные kind, unit, время и отсутствующее поле отвергаются с понятной ошибкой; число в виде строки не принимается.
- [ ] Пустой список не вызывает деление на ноль; timestamps сравниваются по моменту времени.
- [ ] Unit-тесты включают валидный вход, пустой набор и минимум три неверных входа.
