# MO-03 · Сеть, загрузка и повтор запроса

Направление: [Mobile · Dart и Flutter](../../README.md). Ориентир: 8–12 часов после изучения темы. Предыдущий шаг: MO-02.

## Цель

Управлять асинхронными результатами без устаревшего UI.

## Входные материалы

[PulseLab](../../../../docs/01-project/pulselab.md), [fixtures](../../../../shared/fixtures/README.md), [контракты](../../../../shared/contracts/README.md). Используй свой код предыдущего задания; внешний backend/аккаунт/оборудование не являются зависимостью.

## Сделать

Добавь HTTP/mock-client по учебному REST-контракту и смену периода. Fake client должен воспроизводить задержку, 422 и 503. После быстрого переключения фильтра старый ответ не должен заменять новый.

Сначала опиши план из 3–5 шагов, затем реализуй минимальный путь и проверь ошибки. Если выбираешь другую библиотеку, объясни совместимость с технологией направления; замена основного стека требует согласования наставника.

## Критерии приёмки

- [ ] Base URL передаётся через учебную конфигурацию, рабочие URL не используются.
- [ ] Смена фильтра с ответами в обратном порядке сохраняет актуальный результат.
- [ ] Timeout и 503 дают понятное состояние и ограниченный повтор; 422 не повторяется автоматически.
- [ ] Тесты доказывают latest-request-wins, timeout и retry; ресурсы освобождаются при закрытии экрана.
