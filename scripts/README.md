# Проверка учебного ресурса

`python3 scripts/check_repo.py` — offline integrity check без сторонних зависимостей. Проверяет 36 задач/опросников, относительные ссылки, JSON, schema parity, валидные/невалидные Reading fixtures, SOAP/REST соответствие и метки базы знаний.

Для fixtures встроен ограниченный validator только используемого подмножества schema. Он не является полной реализацией JSON Schema. Студент выбирает полноценную библиотеку с включённым date-time format. Checker не проверяет внешние ссылки, установленный Flutter/Bun/AI SDK, реализацию студента и весь спектр секретов. Ручная проверка перед публичным размещением остаётся обязательной.

GitHub workflow вызывает эту команду. Ему не требуются secrets или права записи. Обновление action/runtime версий выполняет lead через review.
