# Развитие методички

Запись и merge выполняют назначенные lead-сотрудники TeleMedHub. Студенты сдают работу в собственных публичных репозиториях. Предложение исправить учебный материал можно оформить issue или pull request из fork; это не даёт прав записи в основной ресурс.

1. Создай ветку с одним содержательным изменением.
2. Укажи учебную цель, уровень, ожидаемые артефакты и критерии проверки.
3. Обнови связанные контракты и fixtures, если меняется учебная модель.
4. Приложи официальный источник и дату проверки для новой технологии.
5. Выполни `python3 scripts/check_repo.py` и проверь diff на чувствительные сведения.
6. Передай PR другому lead для review; merge — после исправления замечаний и прохождения CI.

Описания должны быть доступны новичку. Запрещено включать внутрь методички закрытые примеры, даже если доступ к ним имеет автор PR. Опросники и критерии открыты; варианты устной защиты наставник придумывает при обсуждении.
