# Авторская учебная база знаний

`corpus.json` — восемь небольших документов только о PulseLab. `queries.json` — 17 запросов с dev/test split, relevantDocIds и answerable. Это малый демонстрационный benchmark; его качество не переносится на медицинские задачи.

Золотая метка задана на уровне docId. При оценке сначала спроецируй top-k chunks на docId; порядок определяется первым появлением docId, дубли одного документа не занимают отдельное место. k в Recall@k/MRR@k относится к уникальным документам, а API поиска может выдавать top-k chunks. Опиши этот переход явно и получи достаточно chunks для нужного числа уникальных документов, если они существуют.

Для answerable запроса Recall@k = доля relevantDocIds, найденных в top-k уникальных docId. Итог — среднее по answerable queries. MRR@k = среднее 1/rank первого релевантного документа (0, если его нет в top-k). Unanswerable не включаются в знаменатель этих метрик; для них отдельно показывается доля корректных отказов. При оценке abstention на answerable отдельно показывается доля ошибочных отказов.

У provided dev только один unanswerable: этого мало для устойчивой калибровки. Можно добавить synthetic dev-примеры до настройки, зафиксировав их отдельно; не переносить test-запросы в dev. Все добавления корпуса и запросов сохраняются с fingerprint.

`injection-example.txt` — отдельный adversarial fixture. Он не включён в обычный corpus; добавь его только в изолированный тест. Он содержит вымышленное значение и не является секретом.

Не заменяй справку закрытой документацией или клиническими рекомендациями. Для публичных сторонних текстов сначала проверь возможность использования и атрибуцию; основной маршрут не требует стороннего corpus.
