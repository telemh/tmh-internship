# Вводная диагностика

Цель — выбрать начальный уровень, а не отсеять студента по знанию конкретного фреймворка. Время 60–90 минут; пользоваться официальной документацией можно. Первая попытка — без генерации решения AI.

1. Объясни различие commit, branch и pull request. Создай маленький репозиторий, ветку, коммит и PR в свой main.
2. Выбери любой знакомый язык. Прочитай `shared/fixtures/readings.json`, отфильтруй `s001`, вычисли число записей каждого kind. Не складывай разные единицы.
3. Покажи, как программа ведёт себя при пустом массиве, неизвестном поле и испорченном JSON.
4. Объясни разницу HTTP-клиента, API и базы данных. Что означают 200, 401, 403, 422 и 503?
5. Прочитай небольшой раздел документации на английском; напиши своими словами, что из него можно применить.
6. Опиши, что предпримешь, если задача не запускается: какую информацию соберёшь и что отправишь наставнику.

Артефакт: `docs/entry.md` в личном репозитории — результат, затраченное время и темы, которые пока непонятны. Не включай персональную информацию сверх выбранного GitHub-профиля.

Оценка наставника по четырём пунктам, каждый 0–2: базовая логика; работа с данными; самостоятельный поиск причины; объяснение. 0 — пока не освоено, 1 — с подсказкой, 2 — самостоятельно. Результат не является кадровым решением.

При 0–3 баллах сначала подготовительный этап: основы языка, функции, коллекции, обработка ошибок, JSON, Git, два-три маленьких упражнения. При 4–6 — задачи 01–03 с частыми review. При 7–8 — полный маршрут с самостоятельным планированием. Границы — ориентиры; выбор подтверждается разговором.
