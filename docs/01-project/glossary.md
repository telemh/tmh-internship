# Мини-словарь

| Термин | Значение в заданиях |
| --- | --- |
| МИС / HIS / EHR | Система клиники для медицинских и административных данных |
| RPM | Дистанционный сбор и просмотр измерений; здесь только учебные данные |
| DTO | Структура передачи данных между границами компонентов |
| Runtime-валидация | Проверка реального входа во время выполнения, независимо от статических типов |
| Idempotency | Повтор операции с тем же ключом не создаёт новый эффект |
| Webhook | HTTP-событие, отправляемое источником в приёмник |
| BLE | Bluetooth Low Energy; в обязательных заданиях эмулятор события |
| RBAC / policy | Проверка разрешённой операции и конкретного объекта для субъекта |
| RAG | Поиск контекста и формирование ответа на его основании |
| Embedding | Числовое представление текста для поиска по сходству |
| Readiness / liveness | Готовность обслуживать запросы / жизнеспособность процесса |
| Mock / fake | Управляемая учебная замена внешнего компонента |
| ADR | Короткая запись архитектурного решения, альтернатив и последствий |
| Lock-файл | Фиксация конкретных зависимостей для повторяемой установки |
