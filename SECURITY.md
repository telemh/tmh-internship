# Границы учебной работы

Задания выполняются на личном компьютере и синтетических данных PulseLab. Доступ к исходному коду и сервисам TeleMedHub для этих заданий не требуется и не предоставляется.

## Что допустимо публиковать

Собственный учебный код, предоставленные здесь синтетические fixtures, рисунки учебной архитектуры, результаты локальных тестов, зависимости и инструкции запуска. Название демо — PulseLab; оно не должно выглядеть официальным приложением или сервисом ТелеМедХаб.

## Что не попадает в учебные репозитории

- Любые фрагменты закрытого кода, конфигураций, логов, схем БД или внутренних API компании, даже после переименования.
- Реальные медицинские записи, фотографии, документы, контакты, идентификаторы, сведения о сотрудниках и партнёрах.
- Ключи, токены, пароли, приватные сертификаты, рабочие URL, адреса и пути инфраструктуры, скриншоты внутренних кабинетов.
- Выгрузки закрытых материалов, реальные provider payloads и копии рабочих подписанных ссылок.

«Обезличить» рабочие данные для задания недостаточно: используй только данные, созданные с нуля. Для демонстрации не измеряй себя, друзей и родственников.

## Локальная среда

Порты сервисов доступны только на loopback; БД и хранилище не выставляются в интернет. У каждого стенда собственные учебные секреты, создаваемые локально; `.env` исключён из Git. `.env.example` содержит только пустые значения и безопасные названия переменных. Эмулятор идентификации из задания не считается настоящей аутентификацией и не используется в публичном backend.

Скриншоты снимаются только с учебного проекта. Перед коммитом проверь diff; перед публикацией — также историю Git и артефакты сборки. Автоматическая проверка этого ресурса ищет лишь некоторые очевидные признаки и не заменяет ручную проверку.

## Если случайно опубликовал чувствительный материал

Останови дальнейшую публикацию и сообщи наставнику по согласованному непубличному каналу. Не заводи публичный issue с секретом и не пересылай его в чат AI. Наставник организует отзыв затронутого доступа и очистку истории; удаление файла в новом коммите само по себе не устраняет утечку.

Тесты проводят только против собственного локального учебного стенда. Поиск слабых мест в рабочих сервисах компании не является частью практики.
