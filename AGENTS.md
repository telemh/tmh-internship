# Инструкции для Codex и других помощников

Этот каталог — публичный учебный ресурс TeleMedHub. Развивай его в пределах учебной модели PulseLab.

- Не читай, не копируй и не запрашивай закрытые репозитории, рабочие выгрузки, инфраструктуру и секреты компании.
- Не добавляй реальные адреса компании, конфигурации, provider credentials и медицинские данные. Все примеры создавай независимо и помечай как учебные.
- Сохраняй шесть направлений и стабильные ID задач; у каждой задачи должны быть цель, вход, критерии приёмки, артефакты и опросник.
- Отличай подтверждённый стек ТМХ от предложенных учебных инструментов. Не объявляй эксперимент или выбранную библиотеку production-стандартом.
- Не добавляй готовые решения задач в основной ресурс. Можно добавить маленький изолированный пример, который не решает задание целиком.
- Для учебной инфраструктуры используй локальный доступ, пустые секреты в примерах и конкретные версии зависимостей в решениях студентов.
- Исправляй опечатки, сломанные относительные ссылки и несогласованности самостоятельно. Для изменений состава стека, обязательной нагрузки, лицензии и условий доступа запроси решение владельца.
- После изменений запускай `python3 scripts/check_repo.py` и проверяй согласованность README, каталога задач, контрактов и fixtures.
- Работа с этим каталогом не разрешает публикацию или изменение GitHub-настроек сама по себе. Публикуй, только когда пользователь прямо поручил это действие.

Держи описание PR понятным наставнику: что изменилось, какую учебную проблему решает и как проверено. Не публикуй персональные оценки студентов.
