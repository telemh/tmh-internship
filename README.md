# TeleMedHub · Практика разработчика

Учебный ресурс компании ТелеМедХаб для студентов, которые хотят попробовать задачи медицинского IT и показать свои инженерные навыки. Редакция 1.0 · 7 октября 2026 года.

Здесь используются технологии актуальных компонентов ТМХ, но все задания, модели, контракты и наборы данных созданы независимо для обучения. Это не документация внутренней системы и не её исходный код.

## Начать практику

1. Прочитай [правила работы с данными](SECURITY.md).
2. Пройди [вводную диагностику](docs/00-start/diagnostic.md) и [настрой среду](docs/00-start/environment.md).
3. Выбери с наставником **одно основное направление** из таблицы ниже. Выполнять все 36 задач не требуется.
4. Создай отдельный публичный репозиторий на своём GitHub по [инструкции сдачи](docs/00-start/submission.md).
5. Выполняй задачи 01–06 своего направления по порядку. После каждой заполни ответы на опросник, покажи результат и исправь замечания.

Часы — ориентир выполнения после вводного обучения, не норматив скорости. Знакомство со стеком и вопросы наставнику добавляют время. [Маршруты практики](docs/00-start/routes.md) помогают сократить объём или расширить программу. Для новичка предусмотрен подготовительный этап.

## Общий учебный проект PulseLab

У вымышленного сервиса есть приложение пользователя, кабинет специалиста, журнал измерений, импорт от эмулятора устройства и поиск по справке. Направления объединяют [учебная спецификация](docs/01-project/pulselab.md) и [схема компонентов](docs/01-project/learning-map.md). Каждый студент работает самостоятельно: backend заменяется локальным mock, оборудование и платные сервисы не нужны.

| Каталог | Содержимое |
| --- | --- |
| `docs/00-start/` | Вход, среда, маршруты, GitHub и использование AI |

## Что оценивают

Понимание решения, способность учиться, проверять гипотезы, доводить работу до воспроизводимого результата и учитывать обратную связь. Работающий демо-проект без объяснения решений недостаточен. ChatGPT и Claude разрешены с прозрачным [AI-журналом](docs/00-start/ai-learning.md).

На GitHub публикуется код учебного решения и синтетические демонстрации. Источники компании, сведения о пациентах и рабочая инфраструктура не используются. Персональные оценки и кадровые решения наставники хранят отдельно от публичного ресурса.

Для наставника: [оценивание](assessment/rubric.md), [работа с двумя студентами](assessment/mentor-guide.md), [публикация](maintainers/PUBLISH.md), [актуальность стека](docs/stack.md), [источники](docs/resources.md).

Проверка каталога из его корня: `python3 scripts/check_repo.py`. Команда не устанавливает зависимости и не обращается к внешним сервисам.
